# Final submission checklist

Check items only after verifying them. A scaffold is not a completed submission.

- [ ] Work reflects my own understanding; I can explain every submitted component.
- [ ] Topic and dataset come from the instructor's approved repository.
- [ ] Repository is private; instructor and TA have access.
- [ ] README includes student name and ID, title, topic/dataset, description, objective, structure, and run instructions.
- [ ] GitHub history shows genuine, gradual development with meaningful commits.
- [ ] Dataset is available in the repository or from a documented stable programmatic source.
- [ ] Notebook uses portable relative paths and runs top to bottom in a fresh kernel.
- [ ] Notebook contains code plus Markdown explaining purposes, outputs, tables, and figures.
- [ ] Problem, motivation, unit of analysis, variables, and relevant target are explained.
- [ ] Data types, missing values, duplicates, inconsistencies, and outliers are investigated.
- [ ] Important preprocessing decisions are explained; raw data is preserved.
- [ ] Statistics and visualizations answer the question and are interpreted in words.
- [ ] Methods and libraries are appropriate and were covered in class.
- [ ] Statistical assumptions and reasoning are discussed where relevant.
- [ ] Modeling is justified if used; course-covered evaluation metrics are interpreted.
- [ ] Overfitting/generalization are discussed if a predictive model is used.
- [ ] Main findings answer the question and do not claim unsupported causation.
- [ ] Ethics and dataset/method limitations are discussed.
- [ ] Sensitive-data analysis includes the educational-use/professional-advice disclaimer when applicable.
- [ ] Final report explains the analysis, includes all required sections, and is exported as `report/final_report.pdf`.
- [ ] External sources and assistance are acknowledged according to course policy.
- [ ] Source repository notebooks, code, results, and conclusions have not been copied as my solution.
- [ ] Latest working project is pushed to GitHub and its organization is professional.
