# Phase 1 dataset documentation

**Selected approved topic:** Medical Cost Prediction.<br>
**Local dataset:** `data/raw/insurance.csv`.<br>
**Approved project:** [Medical Cost Prediction](https://github.com/asabbah44/Data-Science-Projects/tree/b170e5ff9104dcbcfacbc431d75cd08422721c91/Medical%20Cost%20Prediction).<br>
**Exact CSV source:** [insurance.csv](https://raw.githubusercontent.com/asabbah44/Data-Science-Projects/b170e5ff9104dcbcfacbc431d75cd08422721c91/Medical%20Cost%20Prediction/insurance.csv).<br>
**Source revision:** `b170e5ff9104dcbcfacbc431d75cd08422721c91`.<br>
**Downloaded:** November 9, 2026.

The unmodified CSV contains 1,338 rows and seven columns: `age`, `sex`, `bmi`, `children`, `smoker`, `region`, and `charges`. Each row represents a beneficiary record, with `charges` as the outcome of interest for the initial question.

This topic was selected because the table is small, its attributes are understandable, and it supports a clear question about smoking status, age, BMI, and charges.

The source description does not establish the original sampling method, collection period, or exact billing period/currency of charges. This project is an educational exercise and does not provide professional advice.
